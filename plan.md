## The four parts (from the assignment PDF)
1. **Audit memo** — what's wrong (prioritized), what to delete/merge (+ redirect handling for those URLs), proposed IA for the slice, what to measure/instrument.
2. **Standards** — a style guide excerpt + one content-type template that would've prevented Part 1's problems, written as rules a reviewer *or a machine* could apply consistently. Apply it: rewrite one real page from the slice, send before/after + rationale.
3. **System** — working prototype of an automated checker that flags one class of problem from Part 1, run against the real docs (claude.com/docs/llms.txt or a scrape). Submit as GitHub link + real output (including a few checker mistakes) + how to evaluate the checker itself (false-positive tolerance & why, how to detect degradation, what keeps it from going stale).
4. **Adoption** — a few paragraphs: how to get product teams (who don't report to this role) to adopt the standard/checker, and what to do about a team that ignores it.

## Explicitly out of scope
